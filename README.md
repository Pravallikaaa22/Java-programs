This repository includes programs related to:

- **Arrays** – Array Operations and Manipulation
- **Strings** – String Methods and String Manipulation
- **Object-Oriented Programming** – Classes, Objects, Constructors and Methods
- **Inheritance** – Code Reusability and Inheritance Concepts

- **Exception Handling** – Handling Runtime and Compile-Time Exceptions

- **Problem Solving** – Logical and Number-Based Programs

## ▶️ How to Execute Java Programs

1. Open the required Java program in your preferred IDE.
2. Make sure Java JDK is installed and configured.
3. Compile the Java file using:

   `javac FileName.java`

4. Execute the compiled program using:

   `java FileName`
